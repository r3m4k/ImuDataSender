# Сборка и загрузка из cmd

Скрипты работают в обычном Windows cmd без Bash. Требуются GNU Make,
ARM GNU Toolchain и, для загрузки, OpenOCD.

Локальные настройки находятся в `.env` в корне проекта. Для нового окружения
скопируйте `.env.example` в `.env` и исправьте пути. Формат — `ИМЯ=значение`,
без `set`, `export` и подстановок переменных. Поддерживаются значения в кавычках.
`BUILD_DIR` задаётся относительно корня проекта, без пробелов.
Пути инструментов могут содержать пробелы; относительные пути задаются от корня проекта.
Локальный `.env` исключён из Git.

Команды из корня проекта:

```cmd
scripts\build.cmd build_all
scripts\build.cmd build_user -j4
scripts\build.cmd rebuild_user -j4
scripts\build.cmd rebuild_all -j4
scripts\build.cmd clean_all
scripts\flash.cmd
```

Цель сборки указывается явно. Также доступны `build_libs`, `rebuild_lib`,
`clean_libs` и `clean_user`. Дополнительные параметры передаются GNU Make.
Скрипт сам задаёт рабочий каталог проекта, поэтому его можно вызывать
из другого каталога по полному пути.

`build_user` получает актуальные ELF и HEX: при необходимости обновляет
системные и USB-объекты. `rebuild_user` предварительно удаляет только
пользовательские объекты, их зависимости и итоговые файлы.
`rebuild_all` удаляет и пересобирает все объекты.

Зависимости заголовков сохраняются рядом с объектами как `.o.d` и `.opp.d`.
При отсутствии такого файла объект перекомпилируется, включая первую сборку
после перехода со старой системы. Изменения флагов и параметров командной строки
пока требуют явной пересборки соответствующих объектов.

`flash.cmd` загружает готовый `%BUILD_DIR%/%PROGRAM_NAME%.elf`, проверяет запись,
сбрасывает МК и завершает OpenOCD. Сборка перед загрузкой не запускается.
Можно передать другой ELF:

```cmd
scripts\flash.cmd Debug_Win\ImuReading.elf
```

Явный путь к ELF разрешается относительно текущего каталога cmd.
Параметр `OPENOCD_CONFIG` разрешается относительно корня проекта либо через
каталог поиска OpenOCD, заданный в `OPENOCD_SCRIPTS_DIR`.
