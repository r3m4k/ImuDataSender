# Задачи USART и общего механизма IRQ

Здесь фиксируются согласованные изменения, отложенные этапы и замечания.
Пункт отмечается выполненным после реализации; выполненные проверки указываются отдельно.

## Реализовано: раздельные операции BaseIRQDevice

- [x] Сделать существующий `register_interrupt()` доступным наследникам через
  `protected`. Он только записывает CRTP-переходник в таблицу векторов.
- [x] Добавить защищённый статический `set_interrupt_priority()` с приоритетами
  по умолчанию из существующих констант. Приоритет задаётся независимо от разрешения IRQ.
- [x] Добавить защищённые статические `enable_interrupt()` и `disable_interrupt()`.
  Они меняют разрешение только своего вектора NVIC, сохраняя приоритет и pending.
- [x] Сохранить CRTP, `irq_device_ptr`, статический переходник и вызов `irq_handler()`.
- [x] Сохранить существующий `InitInterrupt()` с прежней семантикой для таймеров,
  EXTI и старого USART. Их одновременная миграция в этот этап не входит.
- [x] Перевести новый `UsartIRQ.hpp` на раздельные операции базового класса:
  убрать прямую настройку NVIC и дублирование приоритетов из USART-обёртки.
- [x] При установке нового вектора сохранить запрет IRQ до подготовки USART и
  каналов. Начальный приоритет задавать только при первой настройке вектора.
  Последующая регистрация и повторный `Init()` не должны сбрасывать его.
- [x] Оставить общую таблицу владельцев и признак первой настройки вектора
  у диспетчера. Не создавать независимые таблицы или флаги для каждого типа устройства.
- [x] Не добавлять в операции базового класса глобальный `__enable_irq()` или
  очистку pending. Критические секции, согласующие несколько операций, сохраняют
  и восстанавливают исходный `PRIMASK`.
- [x] Обновить документацию базового класса и README USART после реализации.

Реализованный интерфейс:

```cpp
protected:
    void register_interrupt();

    static void set_interrupt_priority(
        uint8_t preemption_priority = DefaultIRQChannelPreemptionPriority,
        uint8_t subpriority = DefaultIRQChannelSubPriority
    );

    static void enable_interrupt();
    static void disable_interrupt();
```
